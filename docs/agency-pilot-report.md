# Пилот агентства «Создатель сайтов»: ТКМ

## Исходное состояние

Сайт размещён на GitHub Pages, но покупка, обратная связь и счётчик обращались к PHP. GitHub Pages не исполняет PHP, поэтому эти сценарии были неработоспособны. SEO-адреса указывали на `http://tkm.ru`, а не на фактический HTTPS-сайт.

## Выполнено

- Исправлены canonical, Open Graph, Twitter, JSON-LD, robots и sitemap.
- Покупка и обратная связь переведены на надёжный контакт по email без серверной формы.
- Удалены из публичной страницы номер карты и QR оплаты.
- Добавлены навигация, skip-link, видимый фокус и режим reduced motion.
- Добавлен блок доверия: границы применения, локальная работа и контакты разработчика.
- Добавлен безопасный GitHub Pages workflow: тесты, статический allowlist и исключение платёжного QR.
- Расширены регрессионные тесты публичного сайта.

## Проверки

- Landing: 7 тестов пройдено.
- Полный доступный набор: 9 тестов пройдено.
- `git diff --check`: ошибок нет.

## Отложено

- Реальные скриншоты приложения и короткая демонстрация.
- Проверенные отзывы специалистов.
- Оферта, возвраты и подключение платёжного провайдера.
- Внешний backend/serverless для заявок, если формы понадобятся снова.
- Lighthouse/Axe и визуальные тесты браузера в CI.

## Публикация

Изменения подготовлены в ветке `agency-pilot`. Публикация на основной сайт требует отдельного подтверждения владельца.
