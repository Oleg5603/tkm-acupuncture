10 классических правил ТКМ — встроены в алгоритм

Программа не просто ищет точки по симптому — она применяет полноценную систему принципов традиционной китайской медицины.

  • Мать-сын (Шэн-цикл) — тонизация/седация по порождающему циклу пяти элементов
  • Полдень-полночь (Цзы-у) — воздействие на антагониста активного меридиана
  • Муж-жена (Ко-цикл) — снятие угнетающего избытка
  • Дед-внук — опосредованное укрепление через смежный элемент
  • Ло-пункты — юань-ло метод для дисбаланса пары меридианов
  • Пять антиков (Шу-точки) — точки матери/сына по элементу меридиана
  • Восемь чудесных меридианов — для хронических конституциональных нарушений
  • Xi-точки — противоболевые точки при острых состояниях
  • Сезонность — корректировка приоритета по текущему сезону
  • Конституция (Ба-ган) — Инь/Ян, Пустота/Полнота, Холод/Жар
