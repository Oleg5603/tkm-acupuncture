# Три самостоятельных продукта ТКМ

- ТКМ для клиентов: https://github.com/Oleg5603/tkm-acupuncture — запуск app/main.py, сборки TKM-demo.spec и TKM-full.spec.
- ТКМП для специалистов: https://github.com/Oleg5603/tkmp-professional — запуск app/tkmp.py, сборка TKMP.spec. Отдельные пациенты, визиты, история и резервные копии.
- ТКМ Веб / сайт Малахова: https://github.com/Oleg5603/tkm-web — действующий сайт https://oleg5603.github.io/tkm-web/.

Каждый репозиторий содержит свои зависимости; соседние рабочие папки не требуются. Изменения общих алгоритмов теперь нужно переносить между продуктами явно и проверять тестами.

Старая Python/Flask веб-версия сохранена в tkm-web/legacy/python-web. Рекламная страница установщика в tkm-acupuncture/landing относится к клиентскому приложению и не заменяет сайт Малахова.
